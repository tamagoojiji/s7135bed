専用パソコンを買う前に ／ 家族と使う Windows パソコン

普段使いの Windows パソコンでも、3 つの設定を守れば Claude Code は安全に使える

結論
  • 専用パソコンは買わなくてよい。専用のユーザー・動画のフォルダ・確認画面の 3 つで守れる。
  • 確認を全部飛ばす 3 つのスイッチだけは、絶対に使わない。
  1. Claude Code 専用のユーザーでログインして使う。家族の Google アカウントは見えなくなる。
  2. 動画保管庫と生成動画のフォルダを作り、「ここ以外は触らない」と書いて伝える。
  3. 確認画面（「やっていい？」と聞く画面）は、書く・消す・送る前に必ず自分で見る。

今日できる設定は 3 つ

設定 1: Claude Code 専用のユーザーを作る。 ユーザーとは、パソコンのアカウント（ログインする人の名前）のことです。自分の部屋をもう 1 つ用意するイメージで、Windows の設定から 1 人分を追加します。パソコンの全部をいじれる権限は付けなくて大丈夫です。この部屋で使えば、家族の Google アカウントもブラウザに覚えさせたパスワードも見えません。

設定 2: 動画保管庫と生成動画のフォルダを作る。 フォルダを見る画面でこの 2 つを作り、その中で Claude Code を始めます。そこに CLAUDE.md を置きます。Claude Code が毎回最初に読むルールのメモで、「このフォルダ以外は触らないこと」と書きます。

設定 3: 確認画面を自分で見る。 AI の手はフォルダの外にも届きます。だから設定 2 のメモと、確認画面の二重で止めます。

--dangerously-skip-permissions は危険！絶対 OK にしない

--dangerously-skip-permissions は、Claude Code を始めるときに後ろに付ける文字列です。読み方はデンジャラスリー・スキップ・パーミッションズです。意味は「危ないと分かったうえで、確認を全部飛ばす」です。

「なんでも許可して」「全部やっていいよ」と書いて頼むのも、ねらいは同じです。確認画面で「今後は聞かない」を何度も押すと、だんだん同じ状態に近づきます。

この 3 つは、どれも確認画面を消してしまいます。すると、書く・消す・送るが確認なしで進みます。面倒でも「今後は聞かない」は選ばず、確認画面を残します。

読むだけでも中身が外に出る。必要なファイル以外は触らせない

Claude Code がファイルを見るだけでも、中身は AI に渡ります。そこから外に出るおそれがあります。だから、読むだけでも安全とは言えません。

対策は、動画保管庫と生成動画のフォルダ以外を触らせないことです。CLAUDE.md の指示に加えて、Claude Code の設定ファイルでも止められます。「ほかのフォルダは読まない」と書いておけます。

書く・消す・送る（上書き保存・削除・ネットに送る・メール送信）はやり直せないので、毎回確認画面を見ます。確認画面に delete・rm・push・send の英単語があれば、いったん手を止めます。どれも「消す」か「外に送る」を表す言葉です。

専用パソコンに分けるのは、仕事のデータか 24 時間動かしっぱなしのとき

お客さんの個人情報や仕事のデータを扱うなら、パソコンを分けた方が安全です。24 時間ずっと動かしっぱなしにする場合も同じです。その間は、確認画面を見る人がいないからです。

CapCut で趣味の動画づくりを自動にするくらいなら、専用パソコンはいりません。専用のユーザー・動画のフォルダ・確認画面の 3 つで足ります。

もう 1 つ: パスワードなどの秘密の文字は、動画保管庫と生成動画のフォルダに置かず、チャットにも貼らない。Claude Code はフォルダの中を読めるので、置けば読まれる。
